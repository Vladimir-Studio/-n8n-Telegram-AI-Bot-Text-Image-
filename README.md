# 🤖 n8n Telegram AI Bot (Text + Image)

Workflow для n8n, который реализует Telegram-бота с поддержкой: - 💬
текстовых ответов через LLM (OpenAI / GigaChat) - 🖼 генерации
изображений по команде `/image` - 🌍 автоматического определения языка
пользователя - ⌨️ индикации "бот печатает..." в Telegram

------------------------------------------------------------------------

## 📌 Возможности

Бот умеет: - отвечать на обычные сообщения через AI-модель -
генерировать изображения по команде: `/image описание` - автоматически
отвечать на языке пользователя - отправлять статус `typing` или
`upload_photo`

------------------------------------------------------------------------

## 🗂 Структура логики

1.  **Telegram Trigger** --- принимает входящие сообщения\
2.  **PreProcessing** --- извлекает:
    -   текст сообщения
    -   команду (`/start`, `/image`, другое)\
3.  **Settings** --- задаёт:
    -   температуру модели
    -   лимит токенов
    -   системный промпт\
4.  **Switch**:
    -   `/start` → текстовый ответ
    -   `/image` → генерация изображения
    -   другое → сообщение об ошибке\
5.  **LLM (OpenAI / GigaChat)** --- формирует ответ\
6.  **Telegram Send Message / Send Photo** --- отправка результата
    пользователю

------------------------------------------------------------------------

## ⚙️ Требования

Перед импортом workflow необходимо: - Установленный **n8n** - Telegram
Bot Token - Доступ к одной из моделей: - OpenAI - или GigaChat

------------------------------------------------------------------------

## 🔐 Credentials

Нужно настроить в n8n: - **Telegram API** - **OpenAI API** (для текстов
и картинок) - или **GigaChat API**

После импорта workflow: 1. Открой узлы с ошибками 2. Привяжи свои
credentials

------------------------------------------------------------------------

## 🚀 Установка

1.  Скачай JSON-файл workflow
2.  В n8n:
    -   `Import workflow`
    -   загрузи JSON
3.  Укажи свои credentials
4.  Активируй workflow
5.  Напиши боту в Telegram

------------------------------------------------------------------------
